# 🛡️ Phishing Analysis Lab

A collection of phishing investigations performed using real-world phishing samples from PhishTank.

The purpose of this project is to simulate the workflow of a Tier 1 SOC Analyst by analyzing phishing infrastructure, extracting Indicators of Compromise (IOCs), documenting findings, and mapping adversary techniques using the MITRE ATT&CK Framework.

---

# Objectives

- Investigate phishing websites
- Analyze malicious infrastructure
- Extract Indicators of Compromise (IOCs)
- Document findings
- Practice SOC incident triage
- Improve Threat Intelligence skills

---

# Tools

- PhishTank
- VirusTotal
- URLScan.io
- WHOIS
- MXToolbox
- ANY.RUN
- Google Safe Browsing
